# Demo Notes

## 90-Second Story

1. Problem: SME owners have transaction data but struggle to turn it into decisions.
2. Upload: Load a sales CSV.
3. Dashboard: Show revenue, profit, margin and top product.
4. Intelligence: Show an anomaly or important pattern.
5. Action: Show three AI-assisted recommendations.
6. Impact: Explain how BizPulse turns raw data into decision support.

## Demo Safety

- Use one tested demo dataset.
- Know the expected KPIs before presenting.
- Keep a screenshot/video backup if internet or API access fails.
- The dashboard should still work if the LLM API fails.
